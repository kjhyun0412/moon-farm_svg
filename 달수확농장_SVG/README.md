`3D-view.html`의 부품 수치를 그대로 옮겨 만든 레이저 커팅용 SVG 모음입니다. 이 폴더의 SVG만 보고 3D 모델과 같은 모양으로 만들 수 있게 정리했습니다.
기존 `달수확농장 시제품_SVG/`와 수치가 다르므로 **이 폴더 파일만** 쓰세요. (기존 폴더는 건드리지 않았습니다.)

> ⚠️ 아직 실제 시험 절단을 하지 않은 도면입니다. 화면 렌더링과 XML 형식 검사까지만 확인했습니다. 커프(절단 폭)와 끼움 여유는 보정하지 않았으니 `01_공차시험조각.svg` 결과로 먼저 맞추세요.

## 1. 좌표계와 단위
- 단위 mm, SVG 1:1 크기. **x = 오른쪽(정면에서 볼 때), y = 위(바닥 = 0), z = 앞쪽(관람자 쪽).** 원점 = 바닥 중앙.
- 외형: 폭 120 × 높이 250 × 깊이 147 (= 옆판 깊이 144 + 앞판 3).
- 안쪽 폭 114, 바닥판 윗면 y = 7, 뒤판 안쪽면 z = -70.5, 앞판 안쪽면 z = +70.5.
- 위치 확인은 `00_조립배치도.svg`(평면도·정면도·좌측면도).

## 4. 주요 접합 규칙
- 박스(S2, S3, S4, S5): 핑거 폭 10, 간격 20, 7개. 옆판 홈 깊이 3 + 0.15, 홈 폭 10 + 0. 상판·바닥판 탭 돌출 3.
- 앞판 S1은 끼움 없이 앞면에 접착(3mm), 뒤판 S6·속판 S7은 안쪽 폭 114에 끼움(필요하면 -0.3 줄여 가공).
- 서는 부품은 바닥판 S9의 슬롯에 탭을 꽂음(S9 슬롯 15개). 슬롯 위치는 3D 좌표에서 환산(u = x + 57, v = z + 70.5).
- 슬롯/탭 여유는 도면에서 두께 + 0.05~0.1, 기울어 서는 부품(사다리)은 두께 + 0.5. 실제 값은 `01_공차시험조각` 결과로 조정.

## 5. 조립 순서(권장)
1. **시험 절단**: `01_공차시험조각`으로 커프·홈 여유 결정 → 이후 파일에 반영. A 홈 게이지는 같은 두께로 자른 끼움판, D 핀 구멍은 2mm 합판 끼움핀, B는 P·Q 쌍을 끼워 보고, C는 캘리퍼스로 실측, E는 손으로 확인, F는 각인 농도를 비교해요.
2. **외장 박스**: S2·S3와 S4·S5를 핑거로 맞춰 접착 → 앞면에 S1 접착(바깥 각인과 금색 도장은 접착 전에).
3. **선반 모듈**: PL 기둥의 슬롯에 SH 선반 3개 탭을 관통 접착 → 선반 아래 BR 받침 접착 → 위에 병·랜턴·화분(+새싹) 올림.
4. **사다리**: LD1 앞면에 LD2 9개 접착 → LD1·LD3 윗탭을 LD4 양끝 슬롯에 함께 끼워 A자로 세움 → CH 발 탭을 LD4 기울어진 슬롯에 꽂음.
5. **울타리**: FR 2개 뒤에 FP 6개 접착(FR 위 파랑 선이 말뚝 위치).
6. **덩굴**: VA·VB·VC에 11번 종이 잎·꽃·별을 04번 파랑 표시 위치에 접착.
7. **바닥 모듈**: S9 파랑 점에 풀잎·작은 꽃 접착 → 슬롯에 기둥(선반 모듈), 울타리, 사다리, 덩굴 3개, 모종삽을 꽂음 → 바구니(BK1~BK5 접착 + 꽃 22개), 물뿌리개, 신발 접착. 기둥은 왼쪽 옆판 안쪽면에 접착.
8. **달**: M1 → M2×4 → MF 순으로 접착(안쪽 빈 공간에 LED/COB) → 지지대 B 2개로 S7 슬롯(B1, B2)에 연결.
9. **뒤쪽 유닛**: S7(+달) + S6 맞춤.
10. **마무리**: 바닥 모듈을 뒤에서 밀어 넣고 → S7+S6 닫기 → 천장 S4 구멍 C1~C7에 실을 통과시켜 별·달 매달기(실 길이 = 246 − y: C1 48, C2 36, C3 68, C4 14, C5 28, C6 44, C7 84 mm).

## 6. 3D-view.html과 다른 점(실제 제작을 위해 바꾼 것)
- **깊이**: 3D 외형 깊이 147을 옆판 144 + 앞판 3으로 구성(겉모습은 동일).
- **사다리**: 3D는 막대 + 가로대 상자. 레이저로는 얇은 판(2mm 앞 다리판, 뒤 다리판)과 발판 덧댐으로 구현. 앞·뒤 다리판 윗끝 간격을 1.44 → 2.0(z ±1.0)으로 조정.
- **덩굴 줄기**: 3D는 공중에 떠 있음 → 바닥판 슬롯에 서는 3mm 합판 줄기로 변경. 폭 1.7 → 3.4. VA는 호 왼쪽 끝(x=-48.5), VB는 x=-46에 맞춤(3D도 같은 값으로 수정). VB는 호와 겹치는 높이(y>189.5)의 잎 3·별 1 생략.
- **앞판 아치 위치(수정됨)**: 처음에는 아치 중심이 앞판 가운데에서 3.7mm 왼쪽(x=-3.7)이었는데, 3D와 SVG 모두 가운데(x=0)로 고쳤어요. S1의 구멍 좌우 여백은 각각 7.9mm예요.
- **달 지지대(B 2개)**: 3D에는 달을 받치는 구조가 없어 새로 추가(속판 S7 슬롯으로 연결).
- **입체 소품 단순화**: 병(투명 디스크 5겹), 화분(3겹), 랜턴(3겹), 바구니(5겹), 물뿌리개(4겹), 신발(2겹 납작 돔)으로 대체. 잎은 평면 마름모(3D는 약간 기울어짐).
- **선반·기둥 두께**: 선반 3.5 → 4mm, 기둥 4.5 → 4mm. 선반이 기둥 안쪽면(x=-51.75)부터 시작하고 탭이 기둥을 관통.
- **아치 거울**: 3D에서도 삭제했기 때문에 도면에 없음.
- **아이 실루엣, 별 55개, 앞판 각인**: 3D의 좌표·텍스처 그대로.

## 7. 아직 정해지지 않은 것
- 커프 보정, 끼움 여유, 금색 각인 농도(`01_공차시험조각` 결과).
- LED 종류와 전선 경로(달 M1에 Ø5 구멍만 표시).
- 작은 소품(신발 10×4, 모종삽, 새싹 등) 가공 가능성: 장비 최소 선폭에 따라 3D 프린터나 구매품으로 대체할 수 있음.
