# 달을 수확하는 농장 · 레이저 커팅 SVG

달을 수확하는 소녀 부크누크(120 × 250 × 147mm)를 레이저 커터로 만들기 위한 도면 모음이에요.

## 처음 보시는 분은
1. **조립 가이드** — 완성 모습, 시트별 부품, 조립 순서를 그림으로 정리했어요.
   - 로컬에서 열기: `달수확농장_SVG/조립가이드.html`
   - 웹에서 보기(GitHub Pages): https://kjhyun0412.github.io/moon-farm_svg/달수확농장_SVG/조립가이드.html
2. **3D 뷰어** — 모델을 돌려 볼 수 있어요. 인터넷 연결이 필요해요.
   - https://kjhyun0412.github.io/moon-farm_svg/달수확농장_SVG/3D-view.html
3. **상세 설명** — 좌표계, 레이어 색, 파일별 부품, 접합 규칙, 조립 순서는 [`달수확농장_SVG/README.md`](달수확농장_SVG/README.md)에 있어요.
